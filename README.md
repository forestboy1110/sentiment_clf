# Persian Sentiment Analyzer

A lightweight Persian Sentiment Analysis application built with:

- Streamlit
- LangChain
- OpenRouter
- GPT-4o-mini

This application analyzes Persian reviews, comments, and customer feedback and classifies them into:

- GOOD
- NEUTRAL
- BAD

The system uses GPT-4o-mini through OpenRouter and returns structured sentiment analysis results with confidence scores and explanations.

---

## Features

✅ Persian sentiment analysis

✅ Structured AI output using Pydantic

✅ Confidence score

✅ Fast GPT-4o-mini inference

✅ Streamlit web interface

✅ Analysis history

✅ Interactive charts

✅ No local ML models required

✅ No PyTorch required
